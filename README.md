# LoRe-MAR: Localise, Then Restore

Official implementation for the paper: **Localise, Then Restore: YOLO-Guided and Synthetically Supervised Adversarial Correction of Dental Metal Artefacts in CBCT, with Independent Two-Branch Validation in a Vietnamese Clinical Cohort**.

## Features
- **Localisation:** YOLO-based instance segmentation of metal and teeth.
- **Synthesiser:** Anatomy-aware synthetic glare generation.
- **Restoration:** Attention-gated cycle-consistent generator.

## Structure
- `preprocess/`: Data generation and synthesis scripts.
- `train/`: Training scripts and models.

## Requirements
- PyTorch
- OpenCV
- scikit-image
- Ultralytics YOLO
